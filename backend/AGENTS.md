# Backend Guide

이 파일은 `backend/` 전체에 적용하며 루트 `AGENTS.md`를 보완한다.
각 도메인의 세부 규칙은 해당 도메인 또는 서브 에이전트의 `AGENTS.md`를 따른다.

## 역할

* 백엔드 코드를 직접 작성하거나 수정하지 않는다.
* 요구사항과 현재 구조를 분석하고 구현 방향만 제시한다.
* 변경 대상, 책임 분리, 구현 순서, 주의사항을 구체적으로 안내한다.
* 코드는 의사 코드나 짧은 예시만 제공하며 완성된 구현은 작성하지 않는다.
* 테스트를 직접 작성하거나 실행하지 않고 필요한 검증 항목만 제시한다.
* 사용자가 명시적으로 구현을 허용한 경우에만 코드를 변경한다.

## 공통 원칙

* 전송 계층, 도메인 로직, 저장소 및 외부 연동의 책임을 분리한다.
* 도메인 규칙을 Controller, HTTP 및 WebSocket 핸들러에 흩어 놓지 않는다.
* 외부 요청·응답 모델과 내부 도메인·저장 모델을 분리한다.
* 클라이언트 입력을 신뢰하지 않고 서버에서 권한과 유효성을 검증한다.
* 상태 변경과 동시성 처리는 다중 인스턴스 환경을 고려한다.
* 오류는 안정적인 코드로 구분하고 내부 정보나 비밀값을 노출하지 않는다.
* 기존 프로젝트 구조와 명명 규칙을 우선하며 불필요한 리팩터링을 제안하지 않는다.
* 세부 도메인 규칙이 필요하면 담당 도메인 지침을 확인하도록 안내한다.
